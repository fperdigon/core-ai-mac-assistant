# Core AI Mac Assistant

A macOS menu bar assistant that notices when you are about to make a mistake. The first feature: it stops a forgotten `caffeinate` from draining your battery after you unplug the charger.

> Status: planning. Nothing is implemented yet. See [docs/PLAN.md](docs/PLAN.md).

## Planned features

- Built-in keep-awake toggle that replaces `caffeinate`.
- Detects sleep assertions started from the command line or by other apps.
- Escalating alerts as the battery drains.
- Local notifications, plus optional Telegram alerts.
- Secrets stored in the macOS Keychain; no telemetry.
